# Agendelle (démo)

Démo cliquable d'Agendelle, l'agenda en ligne des instituts de beauté, une marque de Kookla Platform.

- Version téléphone et version ordinateur (barre latérale, vue semaine, panneaux de détail).
- Côté salon : agenda par praticienne, caisse, fiches clientes, option laser Kookla, marketing, statistiques, réglages.
- Côté cliente : page de l'institut, réservation multi-prestations, épilation laser via Kookla, bons cadeaux, mes rendez-vous.

Toutes les données sont fictives. Aucun paiement, SMS ni email réel n'est envoyé. Les essais restent dans le navigateur.
